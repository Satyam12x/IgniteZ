Green Fleet Planner · User guide

How to use the Green Fleet Planner

The planner answers one question: which ships should run, on which fuel, at what speed — and what does each choice cost and emit? This guide walks through every screen, every control and every number, in the order you will meet them.

1

Starting the planner

From the project folder, once:

uv pip install -e ".[dev,optim,api]"
python scripts/train_model.py        # trains the fuel model (about 2 minutes)

Then every time:

python -m greenfleet.api             # then open http://127.0.0.1:8000

The browser opens on the Plan page and immediately runs the example fleet, so the first thing you see is a finished result (about 4 seconds). The status pill at the top right reads ready when the planner is idle, searching while it works. The bottom-left of the sidebar shows which model is loaded: Model: 1,00,528 audited ship-years · 25,051 ships.

If a yellow bar says "No trained model loaded", run python scripts/train_model.py and restart. The planner still works but predictions are physics-only estimates.

The sidebar has four pages: Plan (the main tool), Fuels (compare fuels over their whole life), Calculator (fuel burn for one ship at any speed), Ports (what each Indian port can supply, by year). Nothing needs the internet after the page has loaded.

2

Plan — the main screen

Setting up

Fleet

Pick a starting fleet. Coastal cargo fleet · 12 ships · 2047 is the demonstration case (clean fuels available at the ports). 2030 is the same fleet when only fossil fuels can be bought. Mormugao harbour tugs is the Green Tug Transition case. Two ships · one route is the simplest possible problem. Choosing a fleet also sets the year and the fuels; you can change them afterwards.

Year

Which year the plan is for. This decides which fuels the ports can actually supply (see Ports) and how clean India's electricity is. The planner will never assign a fuel that cannot be bought at every port on a route in that year.

Fuels you can buy

Tap a fuel to include or exclude it. A ticked chip is included. Six fuels: heavy fuel oil, diesel, LNG, methanol, ammonia, hydrogen. Include only what your ships could really run on and your ports could really supply.

Fleet line

A one-line summary of the fleet as it stands: number of ships, routes and ports, cargo to move each year. It says edited if you have changed ships or routes.

Carbon tax, ₹ per tonne CO₂

A charge on every tonne of CO₂. Leave 0 if none. A tax makes dirty fuels cost more, so cleaner plans become the cheaper ones.

CO₂ limit, tonnes per year

Optional ceiling. Any plan above it is rejected. Leave blank for no limit.

Edit ships & routes

Opens a table where every cell is editable and rows can be added or removed. Column meanings are in the next section.

How each fuel is made

For fuels that can be produced in more than one way, choose the way. This matters enormously: ammonia made from natural gas ("grey") is worse than diesel over its whole life; made with renewable electricity ("green") it is far cleaner. Same for hydrogen. For methanol, choose e-fuel for the renewable version.

Population · Generations · Seed

How hard the search works. Population × Generations = number of complete plans evaluated (30 × 200 = 6,000, the same budget as the published benchmarks; a run takes 3–5 seconds). Raise Generations for a bigger fleet. Seed is the random starting point: the same seed always gives the same answer, a different seed explores differently.

Also run for comparison

Runs standard methods on the same problem with the same budget so you can see how our search compares: NSGA-II (the standard genetic algorithm), Greedy (what a planner does by hand), Random. They add a second or two.

Find plans

Starts the search. A progress bar shows plans checked and plans kept. The button is disabled while searching.

Reading the results

  • Lowest cost — the cheapest plan that delivers everything. Usually all fossil fuel.
  • Balanced — the plan closest to "good on both" (selected by default).
  • Lowest emissions — the cleanest plan that delivers everything.

On each card: ₹ per year (fuel + running costs + any carbon tax), tonnes of CO₂ per year over the whole life of the fuel, % vs diesel (the same ships on the same routes burning diesel — green is less, red is more), ships used, the fuel mix as coloured chips, and whether the plan meets or misses the Harit Sagar target for that year (India's port target: 30% less CO₂ per tonne of cargo by 2030, 70% by 2047).

Click any card to select it.

Chart. Every dot is one complete plan. Further left is cheaper, lower down is cleaner. Dot colour is the main fuel in the plan. The selected plan has a dark ring. Click any dot to select that plan — there are usually more plans than the three cards. Hollow diamonds are the plans the comparison methods found (NSGA-II, greedy), so you can see our search finds plans they miss.

Assignments. One row per ship that sails: route, fuel chip, speed in knots. The last line lists the ships kept in reserve. Hover a fuel chip to see how that fuel is made.

Download saves the selected plan as a file (JSON) with the settings it was made with.

Fuels — compare fuels over their whole life

Energy demand — how much work the engines do in a year: one harbour tug, one coastal ship, or exactly 1 TJ for a per-unit comparison. Only the scale changes; the percentages do not.

Year — matters only for electricity: India's grid gets cleaner each year, so electric options improve.

Show what a funnel-only tool reports — adds a black tick at the figure a tool would give if it counted only what leaves the funnel. For ammonia, hydrogen and electricity that tick sits at zero; the bar shows the truth.

Colours: green bars are cleaner than diesel, red are dirtier, amber means "looks clean at the funnel but is dirtier over the whole life" — those are the fuels a naive comparison gets wrong.

4

Calculator — fuel for one ship at any speed

The big number is tonnes of fuel per 1,000 nautical miles at the chosen speed, with the likely range. Below it: engine power needed, how much slowing down by two knots saves per mile, the most fuel-efficient speed if there were no schedule, and the typical service speed for that ship type.

The chart is the same figure at every speed: the line is the estimate, the shaded band the likely range, the red dot your chosen speed. Slower is cheaper per mile until very slow speeds, where the ship's hotel load (lights, cooling, pumps) starts to dominate.

The badge says what the figure is based on. Based on certificate means the ship's own efficiency figure was used and the model is typically within about 20% on ships it has never seen. Estimate means no certificate was given — the planner uses a typical value for the type and shows a much wider range; plan with the upper end. Harbour tugs are always estimates: they are below the size the data covers.

5

Ports — what each port can supply

✓ available · ◐ limited (small volumes, by arrangement) · ○ planned, not usable yet · ✗ none. The Plan page uses this table: a fuel is allowed on a route only if every port on the route shows ✓ or ◐ in that year. "Planned" is deliberately not enough — a fleet plan built on an uncommissioned facility strands ships.

Chips mark the pilot site (Mormugao), ports in the green tugs programme, and H₂ hub ports designated for green hydrogen.

The grid chart shows the carbon intensity of India's electricity used for shore power and battery-electric ships; values after 2023 are projections.

The years in this table are placeholders with the correct structure. Before any published result, confirm them with each port authority — this is the first task of the pilot.

7

A five-minute walkthrough

Open on the finished result

Read the three cards left to right: cheapest (all HFO, misses the target) → balanced → cleanest (all e-methanol, 91% less than diesel, meets Harit Sagar 2047). Same ships, same cargo.

Click Lowest emissions

Show the assignments: which ship, which route, which fuel, what speed, who stays in reserve. Click a middle dot on the chart to show there are more plans than three.

Switch the fleet to 2030 and press Find plans

Every plan is fossil, every card misses the target. Point at Ports: in 2030 methanol is only planned at Mormugao and Cochin, so the planner refuses to use it.

Untick every fuel except Hydrogen, press Find plans

"No plan delivers all the cargo" — hydrogen is not bunkerable on these routes in that year. The refusal is the feature.

Fuels page

Tick "Show what a funnel-only tool reports": the black ticks at zero for ammonia and hydrogen against the amber bars. Then the three fact cards.

Calculator

Drag the speed from 14 to 12 knots: −24% per mile. Switch the type to Harbour tug: the badge turns to Estimate and the band widens — the tool says when it is guessing.

Back to Plan, scroll to How the search performed

6,000 plans evaluated in a few seconds out of 2.3×10¹³ combinations; hypervolume about level with NSGA-II on 12 ships; the diversity curve falling smoothly.
