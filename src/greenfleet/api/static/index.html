How it works

Three engines work together. Every number in Q Fleet comes from one of them.

1

Predict fuel use

A machine learning model trained on real ship fuel reports predicts how much energy each ship needs at each speed.

2

Count real emissions

Every fuel is counted from well to wake: making it, shipping it, methane slip, N₂O and pilot fuel, not just the funnel.

3

Search for the best plans

A quantum-inspired search (QIEA + QPSO) tries fuel, route and speed for every ship and keeps the plans where cost and CO₂ cannot both improve.
